## Workflow

- Follow [working-standards.md](working-standards.md).

## Behavior

- I'm a developer, but I didn't write the code, so don't show me code unless it can't be avoided.
- Use plain words, no jargon.
- Use emoji freely.
- When you make a mistake, apologize first and name it.
- Never spawn subagents. If a task looks like it will need them, ask at the start.
- Never tell me to run a command; ask whether I want it run, then run it yourself.
- Before any run, check whether it costs money; if it does, ask first.
- Never use more than 75% of the CPU; check before running, and ask if more is needed.
- Never trust docs; the code is the truth of how things behave.
- If you're Claude, never suggest Auto-fix.
- Never write anything outbound (Slack, Linear, GitHub) without asking.
- Never commit or push until I say so.
- Never add Claude as a co-author or contributor in commits or PRs.
- Ask before creating a memory.
- Never touch production or its data; if a task requires it, ask first.
